# 🌻 植物大战僵尸 - 萌萌消

植物大战僵尸主题的羊了个羊类型消除游戏。

## 🎮 游戏玩法

1. **点击**桌面上的牌加入手牌区
2. 收集 **3 张相同图案** 自动消除
3. 手牌区最多 **7 张牌**，满了游戏结束
4. 消除所有牌即可通关

## 🎯 游戏特色

- ✅ **90 张牌** 关卡 1， progressively 增加到 252 张
- ✅ **横七竖八** 的随机布局（±15°旋转）
- ✅ **立体感** 卡牌设计（3D 效果）
- ✅ **流畅动画**：牌从桌面飞入手牌区
- ✅ **12 种植物图案**：🌻 🌱 🌽 🍄 🌵 🌷 🌹 🍀 🌿 🥕 🍅 🥬

### 核心模块

- **PvZMatchGame 类**: 主游戏控制器，管理游戏状态、卡牌生成、消除逻辑
- **渲染系统**: 使用 requestAnimationFrame 实现 60FPS 流畅动画
- **碰撞检测**: 卡牌堆叠层级管理和可点击判定
- **计时系统**: 9 分钟倒计时和超时处理

## 🚀 如何运行

直接双击 `index.html` 在浏览器中打开，或：

```bash
# 使用任意 HTTP 服务器
python -m http.server 8000
# 访问 http://localhost:8000
```

## 📊 游戏配置

| 项目 | 值 |
|------|-----|
| 关卡 1 | 90 张牌，12 种图案 |
| 手牌大小 | 7 格 |
| 时间限制 | 540 秒（9 分钟） |
| 卡牌旋转 | ±15°随机 |
| 消除规则 | 3 张相同图案 |

## 🎨 视觉设计

- **正面牌**：白色/浅灰色背景，图案清晰
- **背面牌**：棕色纹理，无图案
- **立体感**：底部厚度 + 表面高光
- **动画**：桌面 → 向上 → 手牌区（抛物线轨迹）

## 💡 提示

1. 优先点击**上层牌**，露出更多可选项
2. 注意**手牌数量**，避免无意义的牌占位
3. 观察**背面牌**的位置，规划消除顺序

### 代码结构

- `game.js`: 核心游戏逻辑（~600 行）
  - `constructor()`: 初始化游戏配置和状态
  - `createCards()`: 生成卡牌数据
  - `generateStackLayout()`: 创建堆叠布局
  - `assignEmojis()`: 分配植物图案
  - `renderBoard()`: 渲染游戏桌面
  - `handleCardClick()`: 处理点击事件
  - `checkMatches()`: 检测消除组合
