# 🌻 植物大战僵尸 - 萌萌消

植物大战僵尸主题的羊了个羊类型消除游戏。

## 🎮 游戏玩法

1. **点击**桌面上的牌加入手牌区
2. 收集 **3 张相同图案** 自动消除
3. 手牌区最多 **7 张牌**，满了游戏结束
4. 消除所有牌即可通关

## 🎯 游戏特色

- ✅ **90 张牌** 关卡 1， progressively 增加到 252 张
- ✅ **横七竖八** 的随机布局（±15°旋转）
- ✅ **立体感** 卡牌设计（3D 效果）
- ✅ **流畅动画**：牌从桌面飞入手牌区
- ✅ **12 种植物图案**：🌻 🌱 🌽 🍄 🌵 🌷 🌹 🍀 🌿 🥕 🍅 🥬

## 📊 游戏配置

| 项目 | 值 |
|------|-----|
| 关卡 1 | 90 张牌，12 种图案 |
| 手牌大小 | 7 格 |
| 时间限制 | 540 秒（9 分钟） |
| 卡牌旋转 | ±15°随机 |
| 消除规则 | 3 张相同图案 |

## 🎨 视觉设计

- **正面牌**：白色/浅灰色背景，图案清晰
- **背面牌**：棕色纹理，无图案
- **立体感**：底部厚度 + 表面高光
- **动画**：桌面 → 向上 → 手牌区（抛物线轨迹）

## 💡 提示

1. 优先点击**上层牌**，露出更多可选项
2. 注意**手牌数量**，避免无意义的牌占位
3. 观察**背面牌**的位置，规划消除顺序
